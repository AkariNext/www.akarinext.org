# メンバーダッシュボード

Discord でログインしたメンバーは `/dashboard` から、自分の記事とゲーム棚を編集できる。

## できること

- 記事の作成、下書き保存、公開、編集、削除
- 記事のカテゴリー、タグ、既存シリーズ、公開日時、ネタバレ表示、サムネイルの設定
- ゲーム棚への追加、プレイ状態・遊び方・感想・募集状態の編集、削除

シリーズそのものとゲームマスターの追加・編集は引き続き PocketBase 管理画面で行う。

## 権限

`backend/pb_migrations/1787853653_dashboard_editing_rules.js` が次の制約を設定する。

- `posts`: ログイン中のユーザーは `author` が自分の記事だけ作成・更新・削除できる
- `user_games`: ログイン中のユーザーは `user` が自分の行だけ作成・更新・削除できる
- 公開記事と公開プロフィール用のゲーム一覧は従来どおり閲覧できる

フロント側の API でも `author` と `user` はログイン中のユーザー ID に固定する。認証トークンは `httpOnly` Cookie に保存し、ブラウザの JavaScript には渡さない。

## 反映

PocketBase の起動時にマイグレーションが自動適用される。既に起動中の開発環境では PocketBase を再起動し、適用後に `/dashboard` を開く。
